# MSDS QR 예시

공식 공개 한국어 MSDS 6종을 제품별 QR·열람용 갑지·검색 가능한 전체 목록으로 연결한 예시입니다.

- 전체 목록: https://lee-juhyoung.github.io/msds-qr-demo/
- 개별 주소: `document.html?id=제품ID`
- 갑지 7장 PDF: `downloads/msds-covers.pdf`
- 취급·비상대응 요약표 6장 PDF: `downloads/msds-safety-summaries.pdf`
- 원문·갑지·안전요약표·QR 묶음: `downloads/msds-example.zip`
- 공식 출처와 원문 SHA-256: `sources.json`

## 구성

`data.js`의 제품 목록을 두 화면에서 공통으로 읽습니다. 개별 QR과 목록의 제품 링크는 동일한 개별 주소를 사용합니다. 원문 PDF는 `documents/`, 문서 75쪽의 열람 이미지는 `previews/`, 인쇄용 갑지는 `covers/`, QR PNG는 `qr/`에 있습니다. PDF 원문 바이트는 수집한 공식 문서 그대로 보존했습니다.

이번 예시는 경고표지가 아닌 MSDS 열람용 갑지입니다. 실제 사용 제품과 문서가 일치하는지 확인해야 합니다. 문서 개정일과 자료 수집일(2026-10-24)은 구분합니다. WD-40 스페셜리스트 3종은 공식 자료실에서 수집한 2018-10-16 개정 자료이며 최신 개정본으로 주장하지 않습니다. 제조자 또는 공급자가 원문에 표시된 역할을 포괄해 화면에는 제조·공급사로 표시합니다.

제품별 `summaries/제품ID.pdf`는 MSDS 2·4·5·6·7·8항을 발췌한 A4 한 장짜리 취급·비상대응 요약표입니다. 원문의 위험표시, 취급·보관, 보호구, 응급조치, 화재·누출 조치와 원문 QR을 담았습니다. 현장 게시용 보조자료이며 MSDS 원문 및 용기 경고표지와 함께 사용합니다. Specialist 3종의 원문은 2항에 40℃, 7항에 50℃가 병기되어 요약표에는 2항의 40℃ 기준을 적용하고 이를 표기했습니다. 그 밖의 충돌 문구는 유도구토 금지 등 원문의 명확한 예방조치 문구를 유지하고, 소화제는 상충하지 않는 원문 항목으로 정리했습니다.

## 자료 교체

제품 ID와 개별 주소를 유지하면 기존 QR을 계속 사용할 수 있습니다. 같은 제품의 MSDS를 교체할 때 원문 PDF, 해당 페이지 이미지 전체, `data.js`와 `sources.json`의 개정일·분량·해시를 함께 갱신하고, 갑지·안전요약표와 다운로드 묶음도 다시 생성합니다. 제품이 달라지면 새 ID와 새 QR을 사용합니다.

GitHub Pages는 `main` 브랜치의 루트에서 게시합니다. 서버·유료 API·외부 CDN 없이 정적 파일로 동작합니다. 공개 예시 자료만 포함하고 개인 작업계획서 자료는 포함하지 않습니다. 검색엔진 제외 요청은 접근 제한 기능이 아닙니다.
